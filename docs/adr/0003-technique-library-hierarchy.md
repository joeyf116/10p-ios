# ADR-0003 — Technique Library organized by 10th Planet system hierarchy

## Status
Accepted

## Decision
Techniques are organized in three levels: System → Position → Technique. Systems are 10th Planet-specific (Rubber Guard, Lockdown, Electric Chair, Truck, Coyote Guard, etc.).

## Reason
10th Planet Jiu Jitsu is a distinct system with named positions that don't map to traditional BJJ terminology. Organizing by system/position reflects how 10th Planet practitioners actually think about the art and makes content navigable to members at all levels.
